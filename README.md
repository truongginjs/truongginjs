## 🎮 Free browser games I built

No download, no sign-up — play vs the computer or with friends online via room codes.

| Game | What it is |
|---|---|

| [Caro (Gomoku)](https://www.ginjs.click/en/caro/) | Five in a row, Vietnamese rules (blocked both ends doesn't count). Online 1v1 |
| [Tiến Lên](https://www.ginjs.click/en/tien-len/) | The Vietnamese "Thirteen" card game, 2–4 players online with bots |
| [Bulwark](https://www.ginjs.click/en/bulwark/) | Race across a 9×9 board and place walls to block your opponent |
| [Brick Storm](https://www.ginjs.click/en/brick-storm/) | Brick breaker with power-ups and 4-player online co-op |
| [Zombie Rush](https://www.ginjs.click/en/zombie-rush/) | Endless squad zombie shooter |
| [Blade Toss](https://www.ginjs.click/en/blade-toss/) | Throw knives into a spinning log |
| [Who's the Spy?](https://www.ginjs.click/en/who-is-the-spy/) | Pass-the-phone party word game for 3–10 players |

👉 [See all 16 games](https://www.ginjs.click/en/playground/)

**Under the hood:** React + TypeScript + Vite on the front end; a Node.js Socket.IO room server
that re-validates every move server-side, with shared game engines and deterministic physics
replayed in sync on server and clients.
